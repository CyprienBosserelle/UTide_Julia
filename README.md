# UTide_Julia


**UTide.jl** is a native Julia translation and implementation of the Unified Tidal Analysis and Prediction functions. It provides robust harmonic analysis for sea level, current meter, and other time series.

This package brings the UTide methodology to Julia language.

---

## Background & Acknowledgments

This package is a Julia implementation based on previous open-source tidal analysis toolkits:

* **Matlab Reference:** Codiga, D.L. (2011). *Unified Tidal Analysis and Prediction Using Harmonic Analysis with Robust Fitting and Constituent Selection Methods* (UTide). Technical Report 2011-01, Graduate School of Oceanography, University of Rhode Island.
* **Python Reference:** [UTide Python](https://github.com/wesleybowman/UTide) by Wesley Bowman and contributors.

If you use this software in academic research, please ensure you cite the original foundational work by D.L. Codiga.
